# Python OOP - Professional Team Management System ⚽

A simple command-line application built in Python to practice and master **Object-Oriented Programming (OOP)** concepts such as class construction, object composition, instance attributes, and method interactions.

## Features

* **Player Management**: Create individual player profiles with names, positions, and shirt numbers.
* **Team Roster**: Instantiate a team, dynamically set its name via console input, and add players to a roster.
* **Data Retrieval**: Display a complete team roster and count the total number of players using Python built-ins (`len()`).

## Technologies Used

* Python 3
* Git & GitHub for version control

## Code Structure

* **`Player` Class**: Handles individual player attributes (`name`, `position`, `number`).
* **`Team` Class**: Manages the team state, handles dynamic naming (`name_team`), appends players (`add_player`), prints the roster (`show_roaster`), and counts players (`count_players`).
